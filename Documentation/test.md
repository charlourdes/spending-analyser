# Brand Styling Update

To keep the application visually consistent, we should update key interface elements to match our brand colours.

## Updated Components

- Customised buttons
- Pagination controls
- Tables

## Goal

Apply the approved brand palette across these UI elements so the product feels cohesive, polished, and recognisably on-brand.

## Design Requirements

- Use the official brand colours for default, hover, active, and selected states
- Maintain strong contrast for readability and accessibility
- Keep spacing, typography, and borders consistent with the existing design system
- Ensure interactive elements remain clear and easy to use

## Outcome

This update helps create a more consistent user experience and reinforces the visual identity of the brand throughout the application.
